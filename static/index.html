Validador de SKUs

Pegue o suba su lista. Se verifica en Plaza Vea y Makro si el link abre, si el SKU pertenece al producto y si hay stock.

Sin filas

Columnas reconocidas: link, ID del producto, ID de SKU (o RefId), Nombre del producto. Basta con link + SKU, o con ID del producto + SKU.

El SKU falta, no existe o es de otro producto; el ID no coincide; o el link redirige a otro producto.

404: el link no abre o el producto no existe. Sin stock: stock 0 o sin precio.
